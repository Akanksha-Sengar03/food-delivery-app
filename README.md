# 🍔 Food Delivery App

A full-stack food delivery web application built using React, Redux Toolkit, Node.js, and MongoDB.

## 🚀 Features

- User Registration and Login
- JWT Authentication
- Browse Food Items
- Browse Restaurants
- Search and Explore Food
- Add Food Items to Cart
- Update Cart Items and Quantity
- Remove Items from Cart
- Checkout
- Place Orders
- View Order History
- Responsive User Interface
- Redux Toolkit for State Management
- MongoDB for Database Management
- REST API using Node.js

## 🛠️ Tech Stack

### Frontend
- React.js
- React Router
- Redux Toolkit
- JavaScript
- HTML
- CSS

### Backend
- Node.js
- REST API
- JWT Authentication

### Database
- MongoDB
